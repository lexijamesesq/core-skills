# core-skills

This repository is a Claude Code plugin marketplace. Its plugins live under `plugins/`: `core` holds the shared skills and agents, and `estate-hooks` holds the git and pull-request hooks. A change here reaches every project's sessions once it is released and installed, so read a skill's implementation before changing its behavior.

The maintainer's project documentation is in Notion and its work is tracked in Linear; the front matter points to both, and they are private. How to work in this repository is in `AGENTS.md`.
